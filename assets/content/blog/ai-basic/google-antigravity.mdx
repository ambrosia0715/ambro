# Google Antigravity 최신 가이드: 기능, 설치, 활용까지 한 번에

_작성일: 2026-02-09_

2025년 11월 Google Developers Blog에서 공개된 **Google Antigravity**는 “에이전트가 실제로 일을 수행하는(agentic)” 흐름을 IDE에 본격적으로 녹여낸 **차세대 개발 플랫폼(퍼블릭 프리뷰)**입니다. 단순한 자동완성이나 챗봇 사이드바를 넘어서, **여러 에이전트를 동시에 띄우고(Manager surface) 에디터·터미널·브라우저를 가로질러 작업을 끝까지 수행**하게 만드는 것이 핵심이에요.

![Google Antigravity 대표 이미지](assets/images/blog/google_antigravity.webp)

## 1) Antigravity가 ‘AI Dev’에 중요한 이유

지금까지의 AI 코딩 도구가 “코드를 더 빨리 쓰게” 돕는 것에 가깝다면, Antigravity는 “작업을 더 크게 위임하게” 만드는 쪽에 가깝습니다.

- **Editor View**: 익숙한 IDE 흐름(탭 자동완성, 자연어 명령, 코드 편집)을 유지
- **Manager Surface**: 에이전트를 여러 개 띄우고, 비동기적으로(백그라운드) 작업을 진행/관찰
- **Cross-surface Agents**: 에디터뿐 아니라 **터미널 실행, 브라우저 검증**까지 같은 맥락에서 수행

즉, 개발자의 역할이 “구현자”에서 **오케스트레이터(지시·검증·피드백)**로 이동하기 쉬운 구조입니다.

## 2) 핵심 기능: 무엇이 ‘새로운가’

### (1) Manager Surface로 “멀티 에이전트”를 관리

한 명의 개발자가 하던 일을 쪼개서 여러 에이전트에게 동시에 맡길 수 있습니다. 예를 들면:

- A 에이전트: 버그 재현 + 최소 재현 코드 작성
- B 에이전트: 원인 분석 + 수정안 제안
- C 에이전트: 회귀 테스트 추가 + 문서 업데이트

개발자는 결과물을 한 번에 검토하면서 방향만 잡아주면 됩니다.

### (2) Artifacts 기반 검증(로그 대신 “증거”)

에이전트가 남긴 도구 호출 로그를 끝까지 읽는 건 피곤합니다. Antigravity는 이를 대신해 **Artifacts(산출물)** 중심으로 검증하게 설계되었습니다.

- 작업 계획/체크리스트
- 변경 요약
- 스크린샷/브라우저 녹화(검증 증거)

코드 리뷰처럼 산출물에 코멘트를 남기면 에이전트가 반영하는 식의 피드백 루프도 강조됩니다.

### (3) 브라우저 도구: “브라우저-인-더-루프” 검증

문서에 따르면 Antigravity는 Chrome 브라우저를 열고 읽고 제어하여 **개발 중인 웹 페이지를 테스트/검증**할 수 있습니다. 별도의 브라우저 프로필을 사용해 일상 브라우징과 분리하며, 스크린샷/녹화 등을 Artifacts로 제시합니다.

![Browser Tools 설정 화면](https://antigravity.google/assets/image/docs/enable_browser_tools.png)

## 3) 설치 방법(공식 다운로드 기준)

Antigravity는 퍼블릭 프리뷰 기간 동안 개인에게 무료로 제공되며, Windows/macOS/Linux 다운로드를 제공합니다.

### macOS

1. 공식 다운로드 페이지에서 Apple Silicon / Intel 용 DMG를 다운로드합니다.
2. 앱을 Applications로 이동해 실행합니다.
3. 최초 실행 시 **권한(파일/네트워크)** 요청이 나오면 개발 작업에 필요한 범위로 허용합니다.

### Windows

1. 공식 다운로드 페이지에서 x64 또는 ARM64 설치 파일을 다운로드합니다.
2. 설치 후 실행하여 초기 설정을 진행합니다.

### Linux

공식 다운로드 페이지의 Linux 안내에 따라 배포판에 맞는 설치 방식을 선택합니다.

> 설치 링크: `antigravity.google/download`

## 4) 실무 활용법: “어떻게 쓰면 좋은가”

### (1) 기능 단위로 “끝까지 위임”하기

다음처럼 요구사항을 기능 단위로 주고, 검증까지 포함시키면 효과가 큽니다.

```text
목표: 블로그 글 목록에서 'AI Dev' 카테고리 카드 UI를 개선해줘.
조건:
- 카드당 태그 3개까지 노출
- 썸네일이 없으면 기본 이미지
- 변경 후 브라우저에서 렌더링 스크린샷(Artifacts)로 검증 결과 제공
```

### (2) 유지보수/정리 작업은 백그라운드 에이전트로

- 오래된 코드/의존성 정리
- 파일/폴더 구조 정리
- 테스트 추가, 문서 최신화

같은 “긴 작업”은 Manager Surface에 던져두고, 본 작업을 이어가는 방식이 좋습니다.

### (3) 안전하게 쓰는 규칙(중요)

에이전트가 터미널과 파일에 접근할 수 있다는 건 강력하지만, 그만큼 실수의 비용도 큽니다.

- **파괴적 명령(삭제/대량 변경)**은 반드시 확인 단계 포함
- 권한은 필요한 범위로 최소화
- Artifacts(스크린샷/변경 요약)로 **검증 루틴** 만들기

## 결론

Google Antigravity는 “코딩 보조”를 넘어 **작업 위임과 검증의 자동화**를 전면에 둔 IDE/플랫폼입니다. 특히 웹 개발처럼 “코드 변경 → 실행 → 브라우저 확인” 루프가 잦은 팀이라면, 브라우저-인-더-루프와 Artifacts 기반 검증이 생산성에 바로 영향을 줄 수 있어요.

AI Dev 관점에서 추천하는 첫 시작은 간단합니다. **작은 기능 하나를 ‘계획+구현+검증’까지 통째로 위임**해 보고, 팀/개인에게 맞는 검증 기준을 정해보세요.
