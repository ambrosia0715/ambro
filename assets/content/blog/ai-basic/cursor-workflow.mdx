
# Cursor AI 에디터 200% 활용하기: 워크플로우 혁신 가이드

개발자들 사이에서 가장 핫한 에디터를 꼽으라면 단연 **Cursor**일 것입니다. VS Code를 기반으로 만들어져 익숙함을 제공하면서도, 강력한 LLM(Large Language Model) 기능을 내장하여 코딩 생산성을 비약적으로 높여줍니다.

단순히 "코드 짜줘"라고 시키는 것을 넘어, Cursor를 실무 워크플로우에 깊숙이 통합하여 생산성을 200% 끌어올리는 방법을 소개합니다.

## 1. Cursor의 핵심 기능 이해

Cursor는 단순한 자동완성 도구가 아닙니다. 코드베이스 전체를 이해하고 문맥에 맞는 제안을 하는 것이 특징입니다.

![Cursor AI Interface](https://placehold.co/800x400/png?text=Cursor+AI+Workflow)

### 1.1 Command K (Ctrl/Cmd + K)
에디터 내에서 AI에게 직접 지시를 내릴 수 있는 기능입니다.
-   **코드 생성:** "이 함수에 대한 단위 테스트를 작성해줘"
-   **코드 수정:** "이 변수명을 카멜 케이스로 바꾸고 타입을 명시해줘"
-   **리팩토링:** "이 로직을 별도 함수로 분리해줘"

### 1.2 Chat (Ctrl/Cmd + L)
사이드바에서 AI와 대화하며 문제를 해결합니다. `@` 기호를 사용하여 파일, 폴더, 문서를 참조할 수 있습니다.
-   **Codebase Context:** `@Codebase`를 입력하면 프로젝트 전체를 참조하여 답변합니다. "우리 프로젝트의 인증 로직이 어디에 있어?" 같은 질문이 가능합니다.

## 2. 실무 활용 팁: RAG 기반 코딩

Cursor의 가장 강력한 점은 **RAG(Retrieval-Augmented Generation)**를 코딩에 적용한다는 점입니다. 내가 작업 중인 파일뿐만 아니라 연관된 파일들을 AI가 '읽고' 답변하게 만들어야 합니다.

### 2.1 문서 참조 (@Docs)
새로운 라이브러리를 쓸 때 공식 문서를 브라우저에 띄워두고 왔다 갔다 할 필요가 없습니다.
Cursor 설정에서 `Docs`를 추가하고 채팅창에서 `@React Docs` 처럼 호출하면, 최신 문서를 바탕으로 코드를 작성해줍니다.

### 2.2 이미지 투입
UI 개발 시 디자인 시안(Figma 캡처 등)을 채팅창에 드래그 앤 드롭하고 "이 디자인대로 컴포넌트를 만들어줘"라고 요청해보세요. Tailwind CSS 클래스까지 완벽하게 적용된 코드를 얻을 수 있습니다.

## 3. 코드 리뷰와 디버깅

### 3.1 AI 코드 리뷰
커밋하기 전에 변경된 파일을 열고 `Cmd + L`을 눌러 이렇게 요청하세요.
> "이 변경사항에서 버그 가능성이 있거나 성능 문제가 될만한 부분을 리뷰해줘."

### 3.2 에러 자동 수정
터미널에서 에러가 발생하면 `Auto Debug` 버튼이 뜹니다. 이를 클릭하면 Cursor가 에러 로그를 분석하고 수정 제안을 바로 보여줍니다.

## 4. 커스텀 규칙 (.cursorrules)

프로젝트 루트에 `.cursorrules` 파일을 생성하여 AI에게 팀의 코딩 컨벤션을 가르칠 수 있습니다.

```markdown
# .cursorrules 예시

- 모든 함수에는 JSDoc 스타일의 주석을 달 것
- 변수명은 구체적으로 작성할 것 (e.g., `data` -> `userData`)
- React 컴포넌트는 함수형으로 작성할 것
- 스타일링은 Tailwind CSS를 우선 사용할 것
```

이 파일이 있으면 AI가 코드를 생성할 때 항상 이 규칙을 따릅니다. 프롬프트에 매번 "Tailwind 써줘"라고 말할 필요가 없어집니다.

## 결론

Cursor는 단순한 도구의 변화가 아니라 **개발하는 방식의 변화**를 의미합니다. 문법을 외우는 것보다 **무엇을 만들지 정의하고, AI에게 정확한 맥락을 제공하는 능력**이 더 중요해지고 있습니다. 지금 바로 Cursor를 설치하고 AI 페어 프로그래머와 함께 일하는 경험을 시작해보세요.
