# AI를 활용한 코드 리뷰 자동화 시스템 구축

코드 리뷰는 소프트웨어 품질을 유지하는 가장 중요한 활동이지만, 바쁜 개발자들에게는 시간과 에너지가 많이 드는 부담스러운 업무이기도 합니다. "오타 수정", "변수명 컨벤션", "간단한 버그" 같은 기계적인 지적을 하느라 시간을 낭비하고 있진 않나요?

이러한 단순 반복적인 리뷰는 AI에게 맡기고, 사람은 더 고차원적인 아키텍처나 비즈니스 로직 검토에 집중할 수 있도록 **AI 코드 리뷰 자동화 시스템**을 구축하는 방법을 소개합니다.

## 1. 시스템 아키텍처

우리의 목표는 GitHub에 Pull Request(PR)가 올라오면, 자동으로 AI가 코드를 분석하고 코멘트를 남기는 봇을 만드는 것입니다.

1.  **Trigger:** GitHub Actions (PR 생성/수정 이벤트 감지)
2.  **Analyze:** 변경된 코드(Diff) 추출
3.  **Process:** LLM(GPT-4)에게 코드와 리뷰 가이드라인 전송
4.  **Response:** LLM의 분석 결과를 GitHub PR 코멘트로 등록

## 2. GitHub Actions 워크플로우

`.github/workflows/ai-review.yml` 파일을 생성합니다.

```yaml
name: AI Code Review

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run AI Reviewer
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: python scripts/ai_reviewer.py
```

## 3. 프롬프트 엔지니어링: AI를 시니어 개발자로 만들기

AI에게 단순히 "리뷰해줘"라고 하면 "좋네요" 같은 영양가 없는 소리만 할 수 있습니다. 구체적인 페르소나와 지침을 줘야 합니다.

**System Prompt 예시:**
> "너는 구글 출신의 10년 차 시니어 소프트웨어 엔지니어야. 코드를 매우 비판적으로 분석하고, 잠재적인 버그, 보안 취약점, 성능 문제, 클린 코드 위반 사항을 찾아내.
>
> 답변 형식:
> - 파일명과 라인 번호를 명시할 것
> - 문제점 설명 (Why)
> - 개선된 코드 예시 (How)
> - 칭찬이나 잡담은 생략하고 핵심만 말할 것"

## 4. 변경된 코드(Diff) 처리의 핵심

전체 코드를 다 보내면 토큰 비용이 폭발하고 AI가 문맥을 잃을 수 있습니다. `git diff` 명령어를 사용하여 **변경된 부분**과 그 주변 문맥(Context)만 추출하여 전송해야 합니다.

```python
# Python으로 git diff 추출 예시
import subprocess

def get_diff(base, head):
    cmd = f"git diff {base} {head}"
    return subprocess.check_output(cmd, shell=True).decode('utf-8')
```

## 5. 기대 효과와 한계

**효과:**
-   리뷰 대기 시간 단축 (PR 올리자마자 1분 안에 피드백)
-   휴먼 에러(NPE, 리소스 누수 등) 사전 차단
-   팀 내 코딩 컨벤션 강제 (프롬프트에 규칙 추가 시)

**한계:**
-   거대한 비즈니스 로직의 흐름을 완벽히 이해하진 못함
-   가끔 틀린 지적(Hallucination)을 할 수 있음 (사람의 최종 확인 필요)

## 결론

AI 코드 리뷰어는 사람을 대체하는 것이 아니라, **사람이 더 중요한 일에 집중하게 해주는 비서**입니다. 이미 `PR-Agent`, `CodeRabbit` 같은 상용 서비스도 나와 있지만, 직접 구축해보면 LLM을 파이프라인에 통합하는 귀중한 경험을 얻을 수 있습니다. 오늘 당장 여러분의 레포지토리에 AI 리뷰어를 고용해보세요.
