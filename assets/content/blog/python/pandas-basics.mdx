### DataFrame 직접 만들어보기

```python
import pandas as pd

data = {
    "이름": ["김철수", "이영희", "박지민", "최수진", "정민호"],
    "부서": ["개발", "마케팅", "개발", "인사", "마케팅"],
    "연봉": [5500, 4800, 6200, 4500, 5100],
    "경력(년)": [5, 3, 8, 2, 4]
}
df = pd.DataFrame(data)
print(df)
```

## 3. 데이터 선택과 필터링

원하는 데이터만 뽑아내는 것이 데이터 분석의 시작입니다.

### 열(Column) 선택

```python
# 단일 열 선택 → Series 반환
names = df["이름"]

# 복수 열 선택 → DataFrame 반환
subset = df[["이름", "연봉"]]
```

### 행(Row) 선택: loc과 iloc

```python
# loc: 라벨 기반 선택
df.loc[0]            # 인덱스 0인 행
df.loc[0:2, "이름"]  # 인덱스 0~2의 "이름" 열

# iloc: 정수 위치 기반 선택
df.iloc[0]           # 첫 번째 행
df.iloc[0:2, 0:2]   # 처음 2행, 처음 2열
```

### 조건 필터링 (Boolean Indexing)

가장 자주 쓰이는 기능입니다. 조건식이 `True`인 행만 걸러냅니다.

```python
# 연봉 5000 이상인 직원
high_salary = df[df["연봉"] >= 5000]
print(high_salary)
```

```
# 출력:
#     이름    부서    연봉  경력(년)
# 0  김철수    개발  5500       5
# 2  박지민    개발  6200       8
# 4  정민호  마케팅  5100       4
```

```python
# 복합 조건: 개발부서이면서 경력 5년 이상
senior_dev = df[(df["부서"] == "개발") & (df["경력(년)"] >= 5)]

# 마케팅 또는 인사 부서
non_dev = df[df["부서"].isin(["마케팅", "인사"])]

# 이름에 '김'이 포함된 직원
kim = df[df["이름"].str.contains("김")]
```

## 4. 데이터 전처리 실전

실제 데이터는 결측치, 중복, 잘못된 타입 등으로 지저분합니다. 전처리는 분석 시간의 70~80%를 차지할 만큼 중요합니다.

### 결측치(NaN) 처리

```python
import numpy as np

# 결측치가 포함된 데이터 생성
df_messy = pd.DataFrame({
    "상품": ["A", "B", "C", "D"],
    "가격": [1000, np.nan, 3000, np.nan],
    "수량": [10, 20, np.nan, 40]
})

# 결측치 확인
print(df_messy.isnull().sum())
```

```
# 출력:
# 상품    0
# 가격    2
# 수량    1
```

```python
# 결측치가 있는 행 제거
df_clean = df_messy.dropna()

# 결측치를 평균값으로 채우기
df_messy["가격"] = df_messy["가격"].fillna(df_messy["가격"].mean())

# 결측치를 앞의 값으로 채우기 (시계열 데이터에 유용)
df_messy["수량"] = df_messy["수량"].ffill()
```

### 데이터 타입 변환

```python
# 문자열 → 숫자 변환
df["연봉"] = pd.to_numeric(df["연봉"], errors="coerce")

# 문자열 → 날짜 변환
df["입사일"] = pd.to_datetime(df["입사일"], format="%Y-%m-%d")
```

### 새로운 열 추가 (파생 변수)

```python
# 연봉을 월급으로 환산
df["월급"] = (df["연봉"] / 12).round(0).astype(int)

# 경력에 따른 등급 부여
df["등급"] = df["경력(년)"].apply(
    lambda x: "시니어" if x >= 5 else "주니어"
)
print(df[["이름", "등급"]])
```


## 5. 그룹화(GroupBy)와 집계

SQL의 `GROUP BY`와 동일한 개념입니다. 특정 기준으로 묶어서 통계를 구합니다.

```python
# 부서별 평균 연봉
print(df.groupby("부서")["연봉"].mean())
```

```
# 출력:
# 부서
# 개발      5850.0
# 마케팅    4950.0
# 인사      4500.0
```

```python
# 부서별 여러 통계를 한 번에 구하기
summary = df.groupby("부서").agg(
    인원수=("이름", "count"),
    평균연봉=("연봉", "mean"),
    최고연봉=("연봉", "max"),
    평균경력=("경력(년)", "mean")
)
print(summary)
```

```
# 출력:
#         인원수  평균연봉  최고연봉  평균경력
# 부서
# 개발        2   5850.0    6200     6.5
# 마케팅      2   4950.0    5100     3.5
# 인사        1   4500.0    4500     2.0
```

## 7. 성능을 좌우하는 핵심: 벡터화 연산

Pandas를 쓰면서 `for` 루프로 행을 하나씩 순회하는 것은 **Pandas를 안 쓰는 것만 못합니다**. 내부적으로 C/NumPy로 최적화된 벡터 연산을 활용해야 합니다.

```python
import time

# 10만 행 데이터 생성
big_df = pd.DataFrame({"value": range(100_000)})

# Bad: for 루프 (약 3초)
start = time.time()
for i in range(len(big_df)):
    big_df.loc[i, "doubled"] = big_df.loc[i, "value"] * 2
print(f"for 루프: {time.time() - start:.2f}초")

# Good: 벡터화 연산 (약 0.001초)
start = time.time()
big_df["doubled"] = big_df["value"] * 2
print(f"벡터화: {time.time() - start:.4f}초")
```

```
# 출력:
# for 루프: 3.21초
# 벡터화: 0.0008초
```

**약 4000배 차이**입니다. 반드시 벡터화를 사용하세요.

## 결론

Pandas는 방대한 라이브러리이지만, 핵심 패턴만 익히면 대부분의 데이터 업무를 해결할 수 있습니다.

- **데이터 탐색:** `head()`, `info()`, `describe()`로 시작
- **필터링:** Boolean Indexing과 `isin()`으로 원하는 데이터 추출
- **전처리:** `fillna()`, `dropna()`, `apply()`로 데이터 정리
- **집계:** `groupby().agg()`로 부서별/지역별/기간별 통계 산출
- **성능:** `for` 루프 대신 벡터화 연산을 항상 사용

이 5가지를 손에 익히면, 엑셀에서 한 시간 걸리던 작업을 10줄 코드로 끝낼 수 있습니다.
