JSON Formatter

API 응답이나 설정 파일에서 받은 JSON(JavaScript Object Notation) 데이터를 읽기 쉽게 들여쓰기하거나, 전송 용량을 줄이기 위해 압축(Minify)할 때 사용하는 무료 포맷터입니다.

사용 방법

입력창에 유효한 JSON 문자열을 붙여넣은 뒤 Format 버튼을 누르면 2칸 들여쓰기가 적용된 형태로 정렬됩니다. Minify 버튼을 누르면 공백과 줄바꿈이 제거된 한 줄 JSON으로 변환됩니다. 문법 오류가 있으면 오류 메시지가 표시되므로 디버깅 시 참고할 수 있습니다.

활용 예시

로그나 외부 API 응답을 빠르게 확인하거나, 번들 크기를 줄이기 위해 JSON 설정을 minify할 때 활용하세요. 클라이언트에 전달하기 전 유효성 검사 용도로도 쓸 수 있습니다.
