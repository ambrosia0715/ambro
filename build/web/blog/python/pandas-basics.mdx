    <h1>Pandas 데이터 분석 기초</h1>
    <div class="meta">2026-02-04 &middot; 15분 &middot; Ambro</div>
    <img src="/assets/assets/images/blog/pandas_analysis.webp" alt="Pandas 데이터 분석 기초" style="width:100%;border-radius:12px;margin-bottom:2em;">
    <article><h1>Pandas 데이터 분석 기초: 데이터프레임 다루기</h1>
<p>데이터의 시대, 파이썬이 데이터 분석의 표준 언어로 자리 잡은 데에는 <strong>Pandas</strong>라는 강력한 라이브러리의 공이 큽니다. 엑셀(Excel)처럼 데이터를 행과 열로 다룰 수 있게 해주면서도, 프로그래밍적으로 수백만 건의 데이터를 순식간에 처리할 수 있는 도구입니다.</p>
<p>이 글에서는 Pandas의 핵심 자료구조인 <code>DataFrame</code>을 다루는 필수 기법들을 정리하여, 데이터 전처리 및 분석의 기초를 다집니다.</p>
<h2>1. Pandas의 핵심 자료구조</h2>
<h3>Series (시리즈)</h3>
<p>1차원 배열과 유사합니다. 인덱스(Index)와 값(Value)으로 구성됩니다. 하나의 열(Column)이라고 생각하면 됩니다.</p>
<h3>DataFrame (데이터프레임)</h3>
<p>2차원 테이블 구조입니다. 여러 개의 Series가 모여 있는 형태이며, 엑셀 시트나 SQL 테이블과 가장 유사합니다.</p>
<pre><code class="language-python">
import pandas as pd

data = {
    'name': ['Kim', 'Lee', 'Park'],
    'age': [25, 30, 22],
    'city': ['Seoul', 'Busan', 'Incheon']
}
df = pd.DataFrame(data)
print(df)
</code></pre>
<h2>2. 데이터 로딩과 확인</h2>
<p>데이터 분석의 첫 단계는 데이터를 불러오고 훑어보는 것입니다.</p>
<pre><code class="language-python">
# CSV 파일 읽기
df = pd.read_csv('data.csv')

# 상위 5개 행 확인
print(df.head())

# 데이터프레임 정보 확인 (행/열 개수, 데이터 타입, 결측치 등)
print(df.info())

# 기술 통계량 확인 (평균, 표준편차, 최소/최대값 등)
print(df.describe())
</code></pre>
<h2>3. 데이터 선택 및 필터링</h2>
<p>원하는 데이터만 쏙쏙 뽑아내는 능력은 필수적입니다.</p>
<ul>
<li><strong>열 선택:</strong> <code>df['column_name']</code></li>
<li><strong>조건 필터링 (Boolean Indexing):</strong> 30세 이상인 사람만 뽑고 싶다면?</li>
</ul>
<pre><code class="language-python">
# 30세 이상 필터링
over_30 = df[df['age'] &gt;= 30]

# 복합 조건 (AND: &amp;, OR: |)
# 서울에 살면서 25세 미만
target = df[(df['city'] == 'Seoul') &amp; (df['age'] &lt; 25)]
</code></pre>
<h2>4. 데이터 전처리 (Preprocessing)</h2>
<p>실제 데이터는 지저분합니다. 결측치(NaN)를 처리하거나 새로운 파생 변수를 만드는 과정이 필요합니다.</p>
<h3>결측치 처리</h3>
<pre><code class="language-python">
# 결측치가 있는 행 제거
df.dropna()

# 결측치를 특정 값(0)으로 채우기
df.fillna(0)
</code></pre>
<h3>그룹화 (GroupBy)</h3>
<p>특정 기준(예: 도시별)으로 묶어서 통계량을 구할 때 사용합니다. SQL의 <code>GROUP BY</code>와 같습니다.</p>
<pre><code class="language-python">
# 도시별 평균 나이 구하기
avg_age_by_city = df.groupby('city')['age'].mean()
</code></pre>
<h2>5. 실무 팁: 벡터화 연산의 중요성</h2>
<p>Pandas를 쓸 때 <code>for</code> 반복문을 사용하여 행을 하나씩 순회하는 것은 <strong>절대 금물</strong>입니다. Pandas는 내부적으로 C로 구현되어 있어 벡터화 연산(배열 전체에 한 번에 연산 적용)을 지원합니다.</p>
<pre><code class="language-python">
# Bad (매우 느림)
for i in range(len(df)):
    df.loc[i, 'age'] += 1

# Good (매우 빠름)
df['age'] += 1
</code></pre>
<h2>결론</h2>
<p>Pandas는 기능이 워낙 방대하여 모든 것을 외울 수는 없습니다. 하지만 <code>read_csv</code>, <code>head</code>, <code>loc/iloc</code>, <code>groupby</code> 등 핵심 기능만 손에 익혀도 대부분의 데이터 전처리 작업이 가능해집니다. 데이터 분석가를 꿈꾼다면 Pandas를 자유자재로 다루는 것이 그 첫걸음입니다.</p></article>
