    <article><h1>비동기 프로그래밍: Python asyncio 심층 분석</h1>
<p>파이썬은 전통적으로 싱글 스레드 언어(GIL 때문)로 알려져 있어, 높은 동시성 처리가 필요한 작업에 취약하다는 인식이 있었습니다. 하지만 Python 3.4에서 <code>asyncio</code> 라이브러리가 도입되면서, 파이썬으로도 Node.js나 Go처럼 고성능 비동기 I/O 처리가 가능해졌습니다.</p>
<p>이 글에서는 동기와 비동기의 차이점부터 <code>async/await</code> 문법, 그리고 실무에서 <code>asyncio</code>를 제대로 활용하는 패턴까지 깊이 있게 다룹니다.</p>
<h2>1. 동기(Sync) vs 비동기(Async)</h2>
<h3>동기 (Blocking I/O)</h3>
<p>코드가 순차적으로 실행됩니다. 예를 들어, 웹 요청을 보내면 응답이 올 때까지 프로그램은 아무것도 하지 않고 멈춰있습니다(Block). CPU는 놀고 있는데 시간만 흐르는 비효율이 발생합니다.</p>
<h3>비동기 (Non-blocking I/O)</h3>
<p>웹 요청을 보낸 후, 응답을 기다리지 않고 즉시 다음 작업을 수행합니다. 나중에 응답이 오면 그때 다시 돌아와서 처리합니다. 이를 통해 하나의 스레드로도 수천, 수만 개의 I/O 작업을 동시에 처리할 수 있습니다.</p>
<h2>2. 핵심 개념: Coroutine과 Event Loop</h2>
<h3>Coroutine (코루틴)</h3>
<p>일반 함수(<code>def</code>)와 달리 실행을 중간에 멈추고(<code>await</code>) 제어권을 다른 코루틴에 넘겨줄 수 있는 함수입니다. <code>async def</code>로 정의합니다.</p>
<h3>Event Loop (이벤트 루프)</h3>
<p>비동기 작업들의 스케줄러이자 지휘자입니다. 등록된 코루틴들을 순차적으로 조금씩 실행시키며, I/O 대기 상태인 작업은 뒤로 미루고 실행 가능한 작업에 CPU를 할당합니다.</p>
<h2>3. async/await 문법</h2>
<pre><code class="language-python">
import asyncio
import time

async def say_after(delay, what):
    await asyncio.sleep(delay) # 여기서 제어권을 반납하고 대기함
    print(what)

async def main():
    print(f"started at {time.strftime('%X')}")

    # 두 코루틴을 동시에 예약 (Parallel Execution)
    task1 = asyncio.create_task(say_after(1, 'hello'))
    task2 = asyncio.create_task(say_after(2, 'world'))

    # 두 작업이 끝날 때까지 기다림
    await task1
    await task2

    print(f"finished at {time.strftime('%X')}")

asyncio.run(main())
</code></pre>
<p>위 코드는 총 3초가 아니라 약 2초 만에 실행됩니다. <code>sleep</code> 하는 동안 다른 작업이 실행되었기 때문입니다.</p>
<h2>4. 실무 활용 패턴: asyncio.gather</h2>
<p>여러 API를 동시에 호출해야 할 때 <code>asyncio.gather</code>가 강력합니다. 순차적으로 호출하면 <code>1초 + 1초 = 2초</code>가 걸리지만, gather를 쓰면 <code>max(1초, 1초) = 1초</code>가 걸립니다.</p>
<pre><code class="language-python">
async def fetch_url(url):
    # 비동기 HTTP 클라이언트 사용 (예: httpx)
    pass

async def main():
    urls = ['http://google.com', 'http://naver.com', 'http://github.com']
    
    # 세 URL을 동시에 요청
    results = await asyncio.gather(*(fetch_url(url) for url in urls))
    return results
</code></pre>
<h2>5. 주의사항: Blocking 코드 섞어 쓰지 않기</h2>
<p><code>async</code> 함수 내에서 <code>time.sleep()</code>이나 <code>requests</code> 같은 동기 라이브러리를 사용하면 이벤트 루프 전체가 멈춰버립니다(Block). 비동기 세계에서는 반드시 <code>asyncio.sleep()</code>이나 <code>httpx</code>, <code>aiohttp</code> 같은 비동기 지원 라이브러리를 사용해야 합니다.</p>
<h2>결론</h2>
<p><code>asyncio</code>는 I/O 바운드 작업(웹 크롤링, API 서버, DB 쿼리 등)에서 파이썬의 성능을 극한으로 끌어올려 줍니다. FastAPI나 Sanic 같은 모던 웹 프레임워크들도 모두 <code>asyncio</code>를 기반으로 하고 있습니다. 파이썬 개발자라면 이제 <code>async</code>와 <code>await</code>는 선택이 아닌 필수 교양입니다.</p></article>
