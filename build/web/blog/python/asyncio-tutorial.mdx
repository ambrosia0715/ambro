    <article><h1>비동기 프로그래밍: Python asyncio 심층 튜토리얼</h1>
<p>API 서버에서 외부 API 3개를 호출해야 하는 상황을 떠올려 보세요. 각 호출에 1초씩 걸린다면, 동기 코드로는 3초가 필요합니다. 하지만 <code>asyncio</code>를 사용하면? <strong>단 1초</strong>면 충분합니다. 3개의 요청을 동시에 보내고, 가장 느린 응답이 올 때까지만 기다리면 되니까요.</p>
<p>이 글에서는 개념 설명에 그치지 않고, 직접 복사해서 실행할 수 있는 코드와 함께 <code>asyncio</code>의 핵심을 단계별로 파헤칩니다.</p>
<h2>1. 동기 vs 비동기: 체감 성능 차이 확인</h2>
<p>백문이 불여일견. 동기 코드와 비동기 코드의 실행 시간을 직접 비교해봅시다.</p>
<h3>동기 방식 (순차 실행)</h3>
<pre><code class="language-python">
import time

def task(name, seconds):
    print(f"[시작] {name} ({seconds}초 소요 예정)")
    time.sleep(seconds)
    print(f"[완료] {name}")
    return f"{name} 결과"

start = time.time()
results = []
results.append(task("DB 조회", 2))
results.append(task("외부 API 호출", 3))
results.append(task("파일 읽기", 1))
print(f"\n총 소요 시간: {time.time() - start:.1f}초")
print(f"결과: {results}")
</code></pre>
<pre><code class="language-">
# 출력:
# [시작] DB 조회 (2초 소요 예정)
# [완료] DB 조회
# [시작] 외부 API 호출 (3초 소요 예정)
# [완료] 외부 API 호출
# [시작] 파일 읽기 (1초 소요 예정)
# [완료] 파일 읽기
#
# 총 소요 시간: 6.0초
</code></pre>
<p>2 + 3 + 1 = <strong>6초</strong>. 각 작업이 끝날 때까지 다음 작업은 꼼짝도 못합니다.</p>
<h3>비동기 방식 (동시 실행)</h3>
<pre><code class="language-python">
import asyncio
import time

async def task(name, seconds):
    print(f"[시작] {name} ({seconds}초 소요 예정)")
    await asyncio.sleep(seconds)  # 대기 중 다른 작업에 양보
    print(f"[완료] {name}")
    return f"{name} 결과"

async def main():
    start = time.time()
    results = await asyncio.gather(
        task("DB 조회", 2),
        task("외부 API 호출", 3),
        task("파일 읽기", 1),
    )
    print(f"\n총 소요 시간: {time.time() - start:.1f}초")
    print(f"결과: {list(results)}")

asyncio.run(main())
</code></pre>
<pre><code class="language-">
# 출력:
# [시작] DB 조회 (2초 소요 예정)
# [시작] 외부 API 호출 (3초 소요 예정)
# [시작] 파일 읽기 (1초 소요 예정)
# [완료] 파일 읽기
# [완료] DB 조회
# [완료] 외부 API 호출
#
# 총 소요 시간: 3.0초
</code></pre>
<p>세 작업이 <strong>동시에 시작</strong>되어, 가장 오래 걸리는 3초만에 모두 완료됩니다. 6초 → 3초, <strong>50% 성능 향상</strong>입니다.</p>
<h2>2. 핵심 개념 정리</h2>

<h3>Coroutine은 호출만으로 실행되지 않습니다</h3>
<pre><code class="language-python">
async def greet():
    return "안녕하세요"

# 이렇게 하면 실행되지 않음! coroutine 객체만 반환됨
result = greet()
print(result)  # &lt;coroutine object greet at 0x...&gt;
print(type(result))  # &lt;class 'coroutine'&gt;

# 올바른 실행 방법
result = asyncio.run(greet())
print(result)  # 안녕하세요
</code></pre>
<p>이것은 초보자가 가장 많이 하는 실수입니다. <code>async def</code> 함수는 반드시 <code>await</code> 키워드로 호출하거나, <code>asyncio.run()</code>으로 실행해야 합니다.</p>
<h2>3. create_task로 동시 실행 제어하기</h2>
<p><code>asyncio.gather</code>는 편리하지만, 개별 작업의 성공/실패를 세밀하게 제어하려면 <code>create_task</code>가 더 적합합니다.</p>
<pre><code class="language-python">
import asyncio

async def fetch_data(source, delay):
    await asyncio.sleep(delay)
    if source == "서버C":
        raise ConnectionError(f"{source} 연결 실패!")
    return f"{source}: 데이터 수신 완료"

async def main():
    # 각 작업을 Task로 생성
    task_a = asyncio.create_task(fetch_data("서버A", 1))
    task_b = asyncio.create_task(fetch_data("서버B", 2))
    task_c = asyncio.create_task(fetch_data("서버C", 1.5))

    # 개별적으로 예외 처리 가능
    for task in [task_a, task_b, task_c]:
        try:
            result = await task
            print(f"성공: {result}")
        except ConnectionError as e:
            print(f"실패: {e}")

asyncio.run(main())
</code></pre>
<pre><code class="language-">
# 출력:
# 성공: 서버A: 데이터 수신 완료
# 성공: 서버B: 데이터 수신 완료
# 실패: 서버C 연결 실패!
</code></pre>
<h2>4. 실전 패턴: 비동기 HTTP 요청</h2>
<p>실무에서 가장 흔한 사용 사례인 여러 URL 동시 요청을 구현해봅시다. <code>httpx</code> 라이브러리를 사용합니다.</p>
<pre><code class="language-bash">
pip install httpx
</code></pre>
<pre><code class="language-python">
import asyncio
import httpx
import time

async def fetch_url(client, url):
    response = await client.get(url, timeout=10.0)
    return {
        "url": url,
        "status": response.status_code,
        "length": len(response.text)
    }

async def main():
    urls = [
        "https://httpbin.org/delay/1",
        "https://httpbin.org/delay/2",
        "https://httpbin.org/delay/1",
        "https://httpbin.org/get",
        "https://httpbin.org/ip",
    ]

    start = time.time()

    # async with로 클라이언트 자동 정리
    async with httpx.AsyncClient() as client:
        tasks = [fetch_url(client, url) for url in urls]
        results = await asyncio.gather(*tasks)

    for r in results:
        print(f"  {r['url']} → {r['status']} ({r['length']} bytes)")
    print(f"\n총 소요: {time.time() - start:.1f}초 (순차 실행 시 ~5초)")

asyncio.run(main())
</code></pre>
<p>5개 URL을 순차로 요청하면 약 5초 걸리지만, <code>gather</code>로 동시 요청하면 가장 느린 요청 시간인 약 2초에 모두 끝납니다.</p>
<h2>5. 타임아웃과 취소 처리</h2>
<p>네트워크 작업에서는 응답이 오지 않는 상황에 대비해야 합니다. <code>asyncio.wait_for</code>로 타임아웃을 설정할 수 있습니다.</p>
<pre><code class="language-python">
import asyncio

async def slow_operation():
    await asyncio.sleep(10)
    return "완료"

async def main():
    try:
        result = await asyncio.wait_for(slow_operation(), timeout=3.0)
        print(result)
    except asyncio.TimeoutError:
        print("3초 초과! 작업이 취소되었습니다.")

asyncio.run(main())
</code></pre>
<pre><code class="language-">
# 출력: 3초 초과! 작업이 취소되었습니다.
</code></pre>
<h3>Semaphore로 동시 실행 수 제한하기</h3>
<p>API 서버에 동시에 1000개의 요청을 보내면 차단당할 수 있습니다. <code>Semaphore</code>로 동시 실행 수를 제한하세요.</p>
<pre><code class="language-python">
import asyncio

async def fetch_with_limit(sem, task_id):
    async with sem:  # 최대 3개만 동시 실행
        print(f"작업 {task_id} 시작")
        await asyncio.sleep(1)
        print(f"작업 {task_id} 완료")

async def main():
    sem = asyncio.Semaphore(3)
    tasks = [fetch_with_limit(sem, i) for i in range(10)]
    await asyncio.gather(*tasks)

asyncio.run(main())
</code></pre>
<p>이렇게 하면 10개의 작업이 3개씩 묶여서 순차적으로 실행됩니다.</p>
<h2>6. 절대 하면 안 되는 실수 3가지</h2>
<h3>실수 1: async 함수 안에서 time.sleep() 사용</h3>
<pre><code class="language-python">
# 이벤트 루프 전체가 멈춤! (다른 코루틴도 실행 불가)
async def bad_example():
    time.sleep(5)  # 절대 금지

# 올바른 방법
async def good_example():
    await asyncio.sleep(5)  # 대기 중 다른 작업 실행 가능
</code></pre>
<h3>실수 2: 동기 라이브러리를 비동기 코드에서 사용</h3>
<pre><code class="language-python">
# requests는 동기 라이브러리 → 이벤트 루프를 블로킹
import requests
async def bad_fetch():
    response = requests.get("https://api.example.com")  # 블로킹!

# 비동기 라이브러리 사용 (httpx 또는 aiohttp)
import httpx
async def good_fetch():
    async with httpx.AsyncClient() as client:
        response = await client.get("https://api.example.com")
</code></pre>

<h2>결론</h2>
<p><code>asyncio</code>는 I/O 바운드 작업(API 호출, DB 쿼리, 파일 읽기)에서 파이썬의 성능을 극적으로 끌어올리는 도구입니다. 핵심을 정리하면:</p>
<ul>
<li><strong><code>async def</code>로 코루틴 정의</strong>, <strong><code>await</code>로 호출</strong> — 이것이 기본 문법입니다</li>
<li><strong><code>asyncio.gather()</code>로 여러 작업을 동시 실행</strong> — 가장 자주 쓰는 패턴입니다</li>
<li><strong><code>create_task()</code>로 세밀한 에러 처리</strong> — 프로덕션에서 필수입니다</li>
<li><strong>동기 라이브러리를 섞지 마세요</strong> — 한 줄의 <code>time.sleep()</code>이 전체 성능을 망칩니다</li>
