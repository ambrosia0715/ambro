    <article><h1>파이썬 중급 문법: 데코레이터와 제너레이터</h1>
<p>파이썬 기본 문법(변수, 제어문, 함수)을 뗐다면, 이제 코드를 더 파이썬답게(Pythonic) 만들고 효율적으로 작성할 수 있는 중급 문법으로 넘어갈 차례입니다. 그중에서도 <strong>데코레이터(Decorator)</strong>와 <strong>제너레이터(Generator)</strong>는 라이브러리 내부 코드를 이해하거나 고성능 프로그램을 짤 때 필수적인 개념입니다.</p>
<h2>1. 데코레이터 (Decorator)</h2>
<p>데코레이터는 <strong>함수를 수정하지 않고 기능을 추가하거나 확장하고 싶을 때</strong> 사용하는 디자인 패턴입니다. "함수를 감싸는 포장지"라고 생각하면 쉽습니다. <code>@</code> 기호를 사용하여 함수 위에 붙입니다.</p>
<h3>왜 사용하는가?</h3>
<p>로깅(Logging), 실행 시간 측정, 로그인 권한 체크 등 여러 함수에 공통적으로 들어가는 보조 기능(횡단 관심사)을 분리하여 코드 중복을 제거할 수 있습니다.</p>
<h3>작동 원리</h3>
<p>데코레이터는 함수를 인자로 받아, 내부에서 새로운 함수를 정의하고, 그 새로운 함수를 반환하는 고차 함수(Higher-order function)입니다.</p>
<pre><code class="language-python">
import time

# 실행 시간을 측정하는 데코레이터
def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs) # 원래 함수 실행
        end_time = time.time()
        print(f"{func.__name__} 실행 시간: {end_time - start_time}초")
        return result
    return wrapper

@timer_decorator
def heavy_computation():
    time.sleep(1)
    print("계산 완료")

heavy_computation()
# 출력:
# 계산 완료
# heavy_computation 실행 시간: 1.00...초
</code></pre>
<h2>2. 제너레이터 (Generator)</h2>
<p>제너레이터는 <strong>이터레이터(Iterator)를 생성하는 특수한 함수</strong>입니다. 일반 함수는 <code>return</code>을 만나면 값을 반환하고 종료되지만, 제너레이터는 <code>yield</code>를 만나면 값을 호출자에게 전달하고 <strong>잠시 멈춥니다(Suspend)</strong>. 그리고 다음 호출 때 멈춘 지점부터 다시 실행됩니다.</p>
<h3>왜 사용하는가?</h3>
<p><strong>메모리 효율성</strong> 때문입니다. 리스트는 모든 데이터를 메모리에 한 번에 올리지만, 제너레이터는 필요할 때마다 값을 하나씩 생성(Lazy Evaluation)합니다. 수억 건의 데이터를 처리할 때 리스트를 쓰면 메모리 부족(OOM)이 발생하지만, 제너레이터는 문제없습니다.</p>
<h3>사용법</h3>
<pre><code class="language-python">
# 일반 리스트 (모든 숫자를 메모리에 저장)
def get_squares_list(n):
    result = []
    for i in range(n):
        result.append(i ** 2)
    return result

# 제너레이터 (값을 하나씩 생성)
def get_squares_gen(n):
    for i in range(n):
        yield i ** 2

# 제너레이터 표현식 (리스트 내포와 유사)
squares = (i ** 2 for i in range(1000000))

# 사용
for x in get_squares_gen(5):
    print(x)
</code></pre>
<h2>결론</h2>
<ul>
<li><strong>데코레이터:</strong> 코드의 재사용성을 높이고 비즈니스 로직과 보조 로직을 분리하여 코드를 깔끔하게 만듭니다. Flask나 Django 같은 프레임워크에서 라우팅이나 인증 처리에 많이 쓰입니다.</li>
<li><strong>제너레이터:</strong> 대용량 데이터 처리나 스트리밍 데이터 처리 시 메모리를 절약하고 성능을 높이는 핵심 도구입니다.</li>
</ul>
<p>이 두 가지 기능을 자유자재로 다룬다면, 여러분의 파이썬 실력은 이미 중급 이상입니다.</p></article>
