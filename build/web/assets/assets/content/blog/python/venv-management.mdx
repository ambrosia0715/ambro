
# 파이썬 가상환경 관리의 모든 것: venv, virtualenv, conda, poetry

파이썬 프로젝트를 진행하다 보면 필연적으로 패키지 의존성 충돌 문제(Dependency Hell)를 겪게 됩니다. 프로젝트 A는 `pandas 1.0`을 필요로 하고, 프로젝트 B는 `pandas 2.0`을 필요로 한다면 어떻게 해야 할까요?

이때 필요한 것이 바로 **가상환경(Virtual Environment)**입니다. 이 글에서는 파이썬 개발자들이 주로 사용하는 가상환경 도구들을 비교하고, 상황에 맞는 최적의 도구를 선택하는 가이드를 제공합니다.

## 1. 가상환경이 필요한 이유

가상환경은 프로젝트별로 독립적인 패키지 실행 환경을 만들어줍니다. 이를 통해 다음과 같은 이점을 얻을 수 있습니다:

1.  **의존성 격리:** 프로젝트 간 라이브러리 버전 충돌 방지
2.  **재현성 확보:** `requirements.txt` 등을 통해 다른 환경에서도 동일한 실행 환경 구축 가능
3.  **시스템 보호:** 전역(System) 파이썬 환경을 오염시키지 않음

## 2. 주요 도구 비교

### 2.1 venv (내장 모듈)
파이썬 3.3부터 표준 라이브러리에 포함된 모듈입니다. 별도 설치가 필요 없어 가장 가볍고 빠르게 사용할 수 있습니다.

-   **장점:** 설치 불필요, 표준, 가벼움
-   **단점:** 기능이 단순함, 파이썬 버전 관리 기능 없음

```bash
# 가상환경 생성
python3 -m venv .venv

# 가상환경 활성화 (Mac/Linux)
source .venv/bin/activate

# 가상환경 활성화 (Windows)
.venv\Scripts\activate
```

### 2.2 Conda (Anaconda/Miniconda)
데이터 과학 분야에서 표준처럼 쓰이는 도구입니다. 파이썬 패키지뿐만 아니라 C/C++ 라이브러리 의존성까지 관리해주며, 파이썬 인터프리터 버전 자체도 관리할 수 있습니다.

-   **장점:** 강력한 패키지 관리, 파이썬 버전 변경 용이, 바이너리 의존성 해결
-   **단점:** 무거움, 패키지 설치 속도가 느릴 수 있음

```bash
# 파이썬 3.9 환경 생성
conda create -n myenv python=3.9

# 환경 활성화
conda activate myenv
```

### 2.3 Poetry (현대적인 선택)
의존성 관리와 패키징을 위한 최신 도구입니다. `pyproject.toml` 파일을 사용하여 의존성을 명시적으로 관리하며, 의존성 트리 해결(Dependency Resolution) 능력이 뛰어납니다.

-   **장점:** 직관적인 명령어, 의존성 충돌 자동 해결, 빌드/배포 기능 통합
-   **단점:** 별도 설치 필요, 초기 학습 곡선

```bash
# 프로젝트 초기화
poetry init

# 패키지 추가
poetry add fastapi

# 가상환경 쉘 진입
poetry shell
```

## 3. 실무 인사이트: 무엇을 선택해야 할까?

상황에 따라 추천하는 도구가 다릅니다.

1.  **간단한 스크립트나 학습용 프로젝트:** `venv`
    -   가장 빠르고 간편합니다. 복잡한 설정이 필요 없다면 기본이 최고입니다.

2.  **데이터 사이언스, 머신러닝 프로젝트:** `Conda`
    -   `numpy`, `scipy`, `pytorch` 등 C/C++ 의존성이 복잡한 라이브러리를 설치할 때 Conda가 스트레스를 덜어줍니다. GPU 설정 등도 훨씬 수월합니다.

3.  **웹 서비스 개발, 프로덕션 배포용 프로젝트:** `Poetry`
    -   엄격한 버전 관리와 `lock` 파일 시스템이 필수적인 프로덕션 환경에서는 Poetry가 가장 안정적입니다. Docker 컨테이너 빌드 시에도 유리합니다.

## 결론

어떤 도구를 사용하든 **"프로젝트별 가상환경 사용"**은 선택이 아닌 필수입니다. 처음 시작한다면 `venv`로 익숙해진 뒤, 프로젝트 규모가 커지면 `Poetry`로 넘어가는 것을 추천합니다. 데이터 분석가라면 `Miniconda`를 설치하여 가볍게 Conda 환경을 활용해보세요.
