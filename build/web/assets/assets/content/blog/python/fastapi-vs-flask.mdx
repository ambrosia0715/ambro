# FastAPI vs Flask: 모던 파이썬 웹 프레임워크 비교

파이썬 웹 개발 생태계는 오랫동안 Django와 Flask가 양분해 왔습니다. 하지만 최근 몇 년 사이, 압도적인 성능과 개발 경험을 앞세운 **FastAPI**가 혜성처럼 등장하여 판도를 바꾸고 있습니다.

새로운 프로젝트를 시작하려는 당신, 익숙한 Flask를 쓸지, 트렌디한 FastAPI를 쓸지 고민 중이신가요? 두 프레임워크의 장단점을 철저히 비교해 드립니다.

## 1. Flask: 검증된 마이크로 프레임워크

Flask는 "Micro"라는 철학 아래 최소한의 기능만 제공하고 나머지는 개발자의 자유에 맡기는 프레임워크입니다.

### 장점
-   **단순함과 유연성:** 배우기 쉽고 구조가 간단하여 작은 프로젝트나 프로토타입을 빠르게 만드는 데 유리합니다.
-   **방대한 생태계:** 오래된 만큼 수많은 확장 라이브러리(Extension)와 레퍼런스, 커뮤니티 지원이 존재합니다.

### 단점
-   **비동기 지원 부족:** 기본적으로 동기(Sync) 방식이라 고성능 비동기 처리가 어렵습니다. (최신 버전에서 `async` 지원이 추가되었으나, 태생적 한계가 있음)
-   **데이터 검증의 번거로움:** 요청 파라미터를 검증하려면 별도 라이브러리(Marshmallow 등)를 붙여야 하고 코드가 길어집니다.

## 2. FastAPI: 고성능과 생산성의 결정체

FastAPI는 현대적인 파이썬 기능(Type Hint, Asyncio)을 적극 활용하여 만들어진 프레임워크입니다.

### 장점
-   **압도적인 성능:** Node.js나 Go에 필적하는 성능을 냅니다. Starlette(비동기)와 Pydantic(데이터 검증)을 기반으로 하여 매우 빠릅니다.
-   **자동 문서화 (Swagger UI):** 코드만 짜면 대화형 API 문서가 자동으로 생성됩니다. 프론트엔드 개발자와 협업할 때 신세계입니다.
-   **타입 안전성:** Python Type Hint를 강제하여 IDE의 자동완성 지원을 완벽하게 받고, 버그를 컴파일 타임(개발 시점)에 잡을 수 있습니다.
-   **생산성:** 데이터 검증 코드를 따로 짤 필요가 없어 코드 양이 획기적으로 줍니다.

### 단점
-   **상대적으로 적은 레퍼런스:** 빠르게 성장 중이지만, Flask나 Django에 비해 역사가 짧아 자료가 적을 수 있습니다.

## 3. 코드 비교

**Flask**
```python
from flask import Flask, request

app = Flask(__name__)

@app.route('/items', methods=['POST'])
def create_item():
    data = request.json
    # 데이터 검증 로직을 직접 짜야 함
    if 'name' not in data:
        return {"error": "Name required"}, 400
    return {"name": data['name']}
```

**FastAPI**
```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str # 타입 힌트로 자동 검증

@app.post("/items")
def create_item(item: Item):
    return {"name": item.name} # 자동 JSON 변환 및 문서화
```

## 결론: 무엇을 선택해야 할까?

-   **새로운 API 서버를 구축한다면?** 무조건 **FastAPI**를 추천합니다. 성능, 문서화, 개발 생산성 모든 면에서 압도적입니다.
-   **간단한 HTML 렌더링 웹사이트라면?** 템플릿 엔진(Jinja2)과의 통합이 자연스러운 **Flask**가 여전히 편할 수 있습니다.
-   **기존 레거시가 Flask라면?** 굳이 무리해서 바꿀 필요는 없지만, 점진적으로 마이그레이션 하는 것을 고려해볼 만합니다.

FastAPI는 단순히 빠른 프레임워크가 아니라, 파이썬 개발의 패러다임을 "타입 기반"과 "비동기"로 바꾸고 있는 혁신적인 도구입니다.
