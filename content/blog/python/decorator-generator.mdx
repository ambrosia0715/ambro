# 파이썬 중급 문법: 데코레이터와 제너레이터 완벽 가이드

파이썬 기본 문법을 떼고 나서 Flask나 Django 같은 프레임워크 코드를 열어보면, `@app.route("/")`처럼 `@` 기호가 붙은 낯선 문법이 등장합니다. 대용량 파일을 처리하는 코드에서는 `yield`라는 생소한 키워드를 만납니다. 이 둘이 바로 **데코레이터(Decorator)**와 **제너레이터(Generator)**입니다.

이 글에서는 "이게 뭔가" 수준이 아니라, 직접 만들어서 실무에 적용할 수 있는 수준까지 단계별로 배워봅니다.

## 1. 데코레이터 (Decorator)

데코레이터는 **기존 함수를 수정하지 않고 기능을 추가**하는 패턴입니다. 핵심 원리는 "함수가 일급 객체(first-class object)"라는 파이썬의 특성에 있습니다. 파이썬에서는 함수를 변수에 담고, 다른 함수의 인자로 넘기고, 함수에서 함수를 반환할 수 있습니다.

### Step 1: 기본 원리 이해

```python
def my_decorator(func):
    def wrapper():
        print("--- 함수 실행 전 ---")
        func()
        print("--- 함수 실행 후 ---")
    return wrapper

@my_decorator
def say_hello():
    print("안녕하세요!")

say_hello()
```

```
# 출력:
# --- 함수 실행 전 ---
# 안녕하세요!
# --- 함수 실행 후 ---
```

`@my_decorator`는 사실 `say_hello = my_decorator(say_hello)`와 정확히 같은 의미입니다. 원래 함수를 감싸는(wrap) 새 함수를 만들어 반환하는 것이 데코레이터의 전부입니다.

### Step 2: 인자를 받는 데코레이터

실전에서는 원래 함수가 인자를 받는 경우가 대부분입니다. `*args`와 `**kwargs`로 처리합니다.

```python
import time
import functools

def timer(func):
    @functools.wraps(func)  # 원래 함수의 이름, docstring 보존
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"[{func.__name__}] 실행 시간: {elapsed:.4f}초")
        return result
    return wrapper

@timer
def slow_add(a, b):
    """두 수를 더합니다 (느린 버전)."""
    time.sleep(0.5)
    return a + b

result = slow_add(3, 7)
print(f"결과: {result}")
print(f"함수 이름: {slow_add.__name__}")
print(f"Docstring: {slow_add.__doc__}")
```

```
# 출력:
# [slow_add] 실행 시간: 0.5012초
# 결과: 10
# 함수 이름: slow_add
# Docstring: 두 수를 더합니다 (느린 버전).
```

`@functools.wraps(func)`를 빠뜨리면 `slow_add.__name__`이 `"wrapper"`로 바뀌어 디버깅이 어려워집니다. 데코레이터를 만들 때는 항상 `functools.wraps`를 사용하세요.

### Step 3: 인자를 받는 데코레이터 팩토리

재시도 횟수를 지정할 수 있는 retry 데코레이터를 만들어봅시다. 데코레이터에 인자를 전달하려면 함수를 한 겹 더 감쌉니다.

```python
import functools
import time
import random

def retry(max_attempts=3, delay=1.0):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(1, max_attempts + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    print(f"[시도 {attempt}/{max_attempts}] {e}")
                    if attempt < max_attempts:
                        time.sleep(delay)
            raise RuntimeError(f"{max_attempts}회 시도 후 최종 실패")
        return wrapper
    return decorator

@retry(max_attempts=3, delay=0.5)
def unstable_api_call():
    if random.random() < 0.7:
        raise ConnectionError("서버 응답 없음")
    return {"status": "success", "data": [1, 2, 3]}

try:
    result = unstable_api_call()
    print(f"성공: {result}")
except RuntimeError as e:
    print(f"실패: {e}")
```

```
# 출력 (실행마다 다름):
# [시도 1/3] 서버 응답 없음
# [시도 2/3] 서버 응답 없음
# 성공: {'status': 'success', 'data': [1, 2, 3]}
```

### 실무에서 자주 쓰이는 데코레이터 패턴

| 패턴 | 설명 | 사용처 |
|------|------|--------|
| `@timer` | 함수 실행 시간 측정 | 성능 프로파일링 |
| `@retry` | 실패 시 자동 재시도 | API 호출, DB 연결 |
| `@cache` / `@lru_cache` | 결과 캐싱 (메모이제이션) | 반복 연산 최적화 |
| `@login_required` | 인증 여부 확인 | 웹 프레임워크 라우팅 |
| `@validate_input` | 입력값 검증 | 데이터 처리 파이프라인 |

파이썬 3.9부터 표준 라이브러리에 포함된 `@functools.cache`도 알아두면 유용합니다.

```python
from functools import cache

@cache
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(100))  # 354224848179261915075 (캐싱 없으면 사실상 무한대기)
```

## 2. 제너레이터 (Generator)

제너레이터는 **값을 한 번에 다 만들지 않고, 요청할 때마다 하나씩 생성**하는 특수 함수입니다. 핵심 키워드는 `yield`입니다.

### 왜 필요한가: 메모리 문제

10GB짜리 로그 파일을 분석해야 한다고 합시다. 리스트로 전체를 읽으면 메모리가 터집니다.

```python
import sys

# 리스트: 모든 값을 메모리에 올림
numbers_list = [i for i in range(1_000_000)]
print(f"리스트 메모리: {sys.getsizeof(numbers_list):,} bytes")  # ~8MB

# 제너레이터: 값을 하나씩 생성
numbers_gen = (i for i in range(1_000_000))
print(f"제너레이터 메모리: {sys.getsizeof(numbers_gen):,} bytes")  # ~200 bytes
```

```
# 출력:
# 리스트 메모리: 8,448,728 bytes
# 제너레이터 메모리: 200 bytes
```

**백만 개의 데이터**인데 제너레이터는 겨우 200바이트입니다. 값이 필요한 시점에 하나씩 만들기 때문입니다.

### yield의 작동 원리

```python
def countdown(n):
    print(f"카운트다운 시작: {n}")
    while n > 0:
        yield n       # 값을 반환하고 여기서 일시정지
        n -= 1
    print("발사!")

gen = countdown(3)

print(next(gen))  # "카운트다운 시작: 3" 출력 후 3 반환
print(next(gen))  # 2 반환 (yield 다음 줄부터 재개)
print(next(gen))  # 1 반환
# print(next(gen))  # "발사!" 출력 후 StopIteration 예외 발생
```

```
# 출력:
# 카운트다운 시작: 3
# 3
# 2
# 1
```

`yield`를 만나면 값을 돌려주고 **함수 상태를 그대로 보존한 채 일시정지**합니다. 다음 `next()` 호출 시 멈췄던 지점부터 다시 실행됩니다.

### 실전 예제: 대용량 로그 파일 처리

```python
def read_large_file(filepath):
    """파일을 한 줄씩 읽는 제너레이터 (메모리 효율적)"""
    with open(filepath, "r") as f:
        for line in f:
            yield line.strip()

def filter_errors(lines):
    """ERROR가 포함된 라인만 필터링하는 제너레이터"""
    for line in lines:
        if "ERROR" in line:
            yield line

# 파이프라인 구성: 10GB 파일도 메모리 걱정 없이 처리
lines = read_large_file("application.log")
errors = filter_errors(lines)

# 처음 5개 에러만 출력
for i, error in enumerate(errors):
    if i >= 5:
        break
    print(error)
```

이 코드는 파일 크기가 아무리 커도 메모리를 거의 사용하지 않습니다. 제너레이터끼리 체이닝하면 Unix의 파이프(`|`)처럼 데이터 처리 파이프라인을 만들 수 있습니다.

### yield from: 제너레이터 위임

중첩된 제너레이터를 깔끔하게 연결할 때 `yield from`을 사용합니다.

```python
def gen_numbers():
    yield from range(3)     # 0, 1, 2

def gen_letters():
    yield from "abc"        # a, b, c

def combined():
    yield from gen_numbers()
    yield from gen_letters()

print(list(combined()))
```

```
# 출력: [0, 1, 2, 'a', 'b', 'c']
```

## 3. 데코레이터 + 제너레이터 조합

두 개념을 합치면 강력한 유틸리티를 만들 수 있습니다. 제너레이터의 실행 시간을 측정하는 데코레이터를 만들어봅시다.

```python
import functools
import time

def gen_timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        count = 0
        for item in func(*args, **kwargs):
            count += 1
            yield item
        elapsed = time.time() - start
        print(f"[{func.__name__}] {count}개 항목 처리, {elapsed:.2f}초 소요")
    return wrapper

@gen_timer
def process_data(n):
    for i in range(n):
        time.sleep(0.01)
        yield i * 2

results = list(process_data(100))
print(f"결과 개수: {len(results)}")
```

```
# 출력:
# [process_data] 100개 항목 처리, 1.05초 소요
# 결과 개수: 100
```

## 결론

- **데코레이터:** 함수를 수정하지 않고 기능을 추가합니다. `@functools.wraps`를 항상 함께 사용하고, `@retry`, `@timer`, `@cache` 같은 패턴을 익혀두면 실무에서 바로 활용할 수 있습니다.
- **제너레이터:** `yield`로 값을 하나씩 생성하여 메모리를 절약합니다. 대용량 파일 처리, 스트리밍 데이터, 무한 시퀀스 등에서 필수적입니다.

이 두 가지를 자유자재로 다룬다면, 프레임워크 내부 코드를 읽고 이해하는 데 어려움이 없을 것입니다. 여러분의 파이썬 실력은 이미 중급 이상입니다.
